# TrackMate — защищённый менеджер встреч

**TrackMate** — локальное веб-приложение для планирования встреч с расширенными функциями безопасности:

- **Шифрование** всех данных мастер-паролем (Fernet + PBKDF2).
- **Автосохранение** черновиков каждые 10 секунд.
- **ИИ-поиск** информации о контактах через Yandex Search API (YandexGPT).
- **Экспорт** зашифрованного дампа для передачи доверенным лицам.
- **«Атомное уничтожение»** всех данных без возможности восстановления.

---

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/ваш-аккаунт/trackmate.git
cd trackmate
```

### 2. Установите зависимости
```bash
pip install fastapi uvicorn jinja2 python-dotenv cryptography httpx
```

### 3. Настройте переменные окружения
Создайте файл `.env` в корне проекта:
```env
HOST=0.0.0.0
PORT=8000
ENV=development

# Yandex Search API (получите в Yandex Cloud)
YANDEX_API_KEY=ваш_ключ
YANDEX_FOLDER_ID=ваш_folder_id
```

### 4. Запустите приложение
```bash
python main.py
```

Откройте браузер по адресу: [http://localhost:8000](http://localhost:8000)

> **При первом запуске** система попросит установить мастер-пароль — он будет использоваться для шифрования всех данных. **Запомните его!** Без пароля доступ к данным невозможен.

## 🧠 Основные функции

### 📅 Встречи
- Создание, редактирование, удаление.
- Участники (имя, email, роль).
- Статус: запланирована, в процессе, завершена, отменена.
- **Автосохранение** черновиков каждые 10 секунд — можно восстановить при повторном открытии.

### 🤖 ИИ-поиск информации о контактах
- На странице встречи у каждого участника есть кнопка **«Найти ИИ»**.
- При нажатии отправляется запрос к Yandex Search API с запросом:  
  *«Расскажи подробно о человеке: Имя Фамилия, email. Укажи профессию, место работы, образование, публикации, соцсети и другую публичную информацию.»*
- Результат отображается в модальном окне.
- Вы можете сохранить полученный профиль — он привяжется к участнику.

### 🔐 Безопасность
- Все текстовые поля (названия, описания, имена, email, роли, профили) хранятся в **зашифрованном** виде.
- Ключ шифрования генерируется из мастер-пароля и соли (PBKDF2, 100 000 итераций).
- Ключ **не сохраняется на диск** — живёт только в оперативной памяти во время сессии.
- Выход из системы удаляет ключ из памяти.

### 💣 Атомное уничтожение
- Кнопка «Уничтожить все данные» на главной странице.
- Требует подтверждения вводом слова **«УНИЧТОЖИТЬ»**.
- Удаляет все записи из БД и сам файл `trackmate.db`, затем пересоздаёт БД.
- После уничтожения потребуется заново установить мастер-пароль.

### 📥 Экспорт (для передачи доверенному лицу)
- Кнопка «Экспортировать все данные» создаёт файл `trackmate_backup.enc`.
- Файл зашифрован тем же мастер-паролем.
- Доверенное лицо может расшифровать его только с вашим паролем.

## 🗂 Структура базы данных (SQLite)

- `meetings` — встречи (шифруются: title, description).
- `participants` — участники (шифруются: name, email, role), связаны с `meetings`.
- `profiles` — досье на людей (шифруются: name, email, phone, raw_data в JSON).
- `drafts` — черновики автосохранения (шифруются целиком как JSON).
- `secrets` — соль и хеш мастер-пароля, дата последнего входа.
